문제 현황 0문항

1단계는 신규 풀(하루 30문 랜덤 노출·설정 변경 가능)과 강등 풀(상위 단계에서 틀려 내려온 문제)로 이뤄져 함께 노출됩니다. 신규는 30문으로 제한되고 강등분이 쌓여 점점 늘어납니다. 각 문제의 ✗숫자는 틀린 횟수입니다. 단계별 현재 문항수 / 총문항수이며, 5단계는 오늘 틀린 재학습 풀이라 아침엔 0이고 풀이가 진행될수록 늘어납니다. 5단계를 비우면 통과분은 2단계, 미통과분은 1단계로 옮겨집니다.

오늘의 학습 동선 매일 학습 순서

6단계는 매일의 학습 순서입니다 — ① 신규 30문 + 어제 틀린 문제 풀이 → ②③④ 1·2·3단계 통과 문제를 2·4·8일 후 재풀이 → ⑤ 오늘 각 단계에서 틀린 문제 재풀이(아침 0 → 진행하며 증가) → ⑥ 클리어 문제 순삭독서. 맞으면 승급, 틀리면 5단계(오늘 재학습)로 모였다가 1단계로 정착합니다.

1→5단계 오늘 풀 문제 (신규·재풀이)

⑥ 6단계 클리어 순삭독서는 양이 많아 여기 대신 주간계획표 › 누적적 읽기에서 요일별로 (문제–단답형 지문) 형식으로 진행합니다.

문제 등록 단일 / 일괄

문제 내용(지문·정답·해설)을 직접 담습니다. 등록하면 1단계에 올라가고, 맞으면 즉시 2단계 → 2·4·8일 후 재풀이 → 4단계 통과 시 6단계 클리어, 틀리면 1단계로 내려옵니다.
